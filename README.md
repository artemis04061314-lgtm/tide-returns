# 潮汐歸還了什麼

臺灣收回的海洋廢棄物，撈上岸之後經過暫置、分類，漁網、保麗龍、寶特瓶與竹架各自的去向、再利用比例與卡關之處。

單一檔案網頁：`index.html`（圖片已內嵌，無需其他檔案）。

## 本機開啟
直接用瀏覽器開啟 `index.html`。

## 發布到 GitHub Pages
1. 把 `index.html` 與 `README.md` 放進新的 repository 根目錄。
2. 到 Settings → Pages，Source 選 Deploy from a branch，Branch 選 `main`、資料夾 `/ (root)`。
3. 數分鐘後網址為 `https://<帳號>.github.io/<repository 名稱>/`。

## 資料與圖片
- 數字與出處列在頁面最後的「資料來源」，主要來自海洋委員會海洋保育署、環境部與新聞報導。
- 插畫為 Gemini 生成。
